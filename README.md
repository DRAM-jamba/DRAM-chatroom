# DRAM-chatroom
A session based app for communication between users.
## Planned features
- One to one chat
- Group chat
- Voicechat
- Friend system
- Session moderation
## Installation for development
1. [Download and install required dependancies](https://tauri.app/start/prerequisites/)
2. Clone the repo (or any other alternative method)
`git clone https://github.com/yourusername/linklocal.git`
`cd linklocal`
3. Install frontend dependencies
`npm install`
4. Run during development
`npm run tauri dev`
